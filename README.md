# mktlink

Сервис «ссылка на товар → канонический URL + название + продавец» для **Ozon,
Wildberries и Яндекс.Маркета**.

Репозиторий раньше держал батч-скрейпер цен на детское питание (19 магазинов,
прогон раз в сутки, выгрузка в XLSX и Google Sheets). Он удалён: это была
другая задача — категорийный листинг с браузером на каждый прогон, а здесь
одна карточка за фиксированный бюджет.

Из него переиспользовано **знание**, а не код, и каждое переиспользование
подписано в docstring'е соответствующего модуля со ссылкой на файл и строку
удалённого кода. Два его отказа, объясняющие, почему наши функции устроены
иначе, сохранены как исполняемые эталоны в `tests/legacy_reference.py` — они
проверяются тестами, а не пересказываются в комментарии. Сам код доступен в
истории git до коммита `841dac3`.

## Что это делает

```http
POST /v1/product
{"url": "https://ozon.ru/t/AbC123"}
```

```json
{"status": "ok",
 "url": {"submitted": "https://ozon.ru/t/AbC123",
         "canonical": "https://www.ozon.ru/product/smes-1234567890/", "hops": 2},
 "product": {"name": "Смесь Nutrilon 1", "sku_id": "1234567890"},
 "seller": {"name": "ООО «Ромашка»", "kind": "third_party", "status": "resolved",
            "source": "ozon:state:webCurrentSeller-4422.name"}}
```

Короткие ссылки из мобильных приложений раскручиваются до настоящего URL.
Прокси покупаются, продлеваются и заменяются автоматически через proxy6.net.

## Четыре ограничения, из которых выведено всё остальное

1. **Три маркетплейса.** Всё остальное отвечает `422` за единицы миллисекунд.
2. **2–3 запроса в минуту.** Не в секунду. Отсюда один файл SQLite вместо
   Postgres с Redis, min-interval guard вместо токен-бакетов и отсутствие
   очередей, сброса нагрузки и сайзинга по закону Литтла.
3. **Пул не закупается впрок.** На старте переиспользуем купленное, иначе
   покупаем ровно один адрес. Растём только заменой.
4. **Потолок ответа — параметр**, `MKTLINK_RESPONSE_BUDGET_MS`, диапазон
   5000…30000, по умолчанию **30000**.

### Почему дефолт 30000

Число выведено из замера, а не из осторожности. Карточка Ozon через
скрейпинг-API отдаётся **9.1–25.6 с** (одиннадцать наблюдений): при потолке
15 с ступень получала 13.5 с и укладывалась примерно в половине случаев,
остальное уходило в `202`. Тридцать секунд покрывают самое медленное
наблюдение с запасом на сокращение ссылки.

Wildberries при этом идёт за 0.6 с, а попадание в кэш — за единицы
миллисекунд: потолок оплачивает ровно один маркетплейс.

**Чем за это заплачено, названо прямо.** Удвоение времени удержания слота
удваивает загрузку балкхеда: по закону Литтла `L = λ·B` растёт с 0.75 до
1.5, и вероятность быстрого `503` выросла бы с 0.11 % до 1.86 % — в
семнадцать раз. Поэтому `GLOBAL_SEMAPHORE` поднят с 4 до 6, что возвращает
исходную вероятность.

Посмотреть, что ручка делает с лестницами:

```bash
mkt budget --budget-ms 5000
mkt budget --budget-ms 30000
```

### Два эндпоинта, а не один

`POST /v1/product` — карточка: до 30 с и до 35 кредитов скрейпинг-API.
`POST /v1/resolve` — только короткая ссылка в каноническую: до 4 с, ноль
кредитов. Развернув ссылку один раз, клиент за раскрутку больше не платит
никогда. Подробно — в разделе
[«Два эндпоинта и когда какой»](#два-эндпоинта-и-когда-какой).

### Кэш результата

Срок свежести — **сутки** на модельном URL и **неделя** на закреплённом
оффере. Прежние 900 с защищали цену как «свойство аукциона», но цены в
ответе нет вовсе: ни одного денежного поля в схеме. Устаревает только
продавец на модельном URL, о чём и предупреждает `offer.stable`.

Суточный срок обязан быть честным и обратимым, поэтому: возраст приходит в
`meta.detail.age_s` и на попадании тоже, а `force_refresh: true` обходит
кэш целиком — вчетверо дороже холодного запроса, потому что сброс кэша это
самый дешёвый способ сжечь чужую квоту кредитов.

Redis (`MKTLINK_REDIS_URL`) — необязательный средний уровень. Без него всё
работает на памяти процесса и SQLite; его падение — промах, а не отказ.

## Что достижимо, а что нет

proxy6.net продаёт **датацентровые** IPv4, и это главное ограничение.

**Все три строки — замер, а не оценка.** Проверено 2026-09-03 на живых
ссылках через купленный IPv4 Shared от proxy6.

| | достижимость | замер |
|---|---|---|
| **Wildberries** | **РАБОТАЕТ** | `card.wb.ru/cards/v4/detail`, HTTP 200 без cookie и без браузера. Название и продавец получены: `BASKEY`, `supplierId=55588`. 571 мс холодный запрос, 1 мс из кэша |
| **Ozon** | **НЕ достижим** | 403 и curl_cffi, и Camoufox 152 с `geoip=True`, на главной и на карточке. Адрес в блок-листе — подробности ниже |
| **Яндекс.Маркет** | **НЕ достижим** | 302 → `/showcaptcha` («Вы не робот?»). Одинаково с cookie и без, одинаково curl_cffi и Camoufox |

Остальные магазины не предлагаются и не будут: ServicePipe не пробивается из
датацентра ни stealth-браузером, ни платным scraping-API — это доказано
четырьмя откатами в истории репозитория (`addfdc5 → 62b049f` и
`b50ab72 → 841dac3`, оба возврата).

### Замер по Я.Маркету: SmartCaptcha, и лёгкий jar не помогает

| попытка | результат |
|---|---|
| `curl_cffi` без cookie | `302` → `/showcaptcha?cc=1`, ставит `yandexuid` и `spravka` |
| `curl_cffi` + лёгкий jar с главной | `302` → `/showcaptcha`, то же |
| Camoufox 152 через прокси | `200` на `/showcaptcha`, заголовок «Вы не робот?» |

Челлендж приходит **на том же хосте** `market.yandex.ru`, поэтому проверка
хоста его пропускает — ловит только путевое veto, ради которого оно и
написано. Без него раскрутчик объявил бы страницу капчи каноническим URL.

Вывод дизайна подтверждён: для Я.Маркета это **челлендж, а не репутация
адреса**, и эскалация тарифа v3 → v4 его не решает. Нужно либо решать капчу,
либо резидентный адрес.

### Замер по Ozon от 2026-09-03: не достижим с датацентрового адреса

Проверено на живой ссылке из мобильного приложения через купленный
IPv4 Shared от proxy6:

| попытка | результат |
|---|---|
| `curl_cffi` без cookie | `307` + `Set-Cookie: __Secure-ETC`, затем `403` |
| Camoufox 152 через прокси | `403`, заголовок «Похоже, нет соединения» |
| Camoufox 152 + `geoip=True` | `403`, то же — и на главной, и на карточке |
| Camoufox 152 **без** прокси | `403`, но заголовок **«Antibot Captcha»** |

Последняя строка — самая важная. **Через датацентровый адрес Ozon отвечает
ХУЖЕ, чем без прокси:** напрямую он предлагает челлендж, а через прокси
маскирует отказ под сетевую ошибку и челленджа не предлагает вовсе. Значит
адрес не «недоверенный», а в блок-листе, и качество отпечатка тут ни при чём.

Прямое следствие: **эскалация тарифа v3 → v4 у Ozon задачу не решает** —
выделенность адреса не меняет его принадлежность датацентру. Чтобы Ozon
заработал, нужны российские резидентные прокси от другого поставщика; это
смена поставщика, а не правка кода.

Конвейер минтинга при этом отработал правильно и ничего не соврал: Camoufox
снял cookie за 9788 мс (оценка дизайна была 9–19 с), сверка отпечатка прошла,
`verify_replay` дал 403 — и jar **не был опубликован**. Сервис отвечает
`202 pending` с каноническим URL, а не выдуманными данными.

### Через скрейпинг-API

Все замеры выше сделаны с **датацентрового адреса вне России** — то есть с
двумя независимыми минусами сразу. Поэтому отрицательные результаты по Ozon
и Я.Маркету доказывали непригодность адреса, а не схемы: через scrape.do с
`geoCode=ru&super=true` те же ссылки отдаются целиком.

| | результат | время | кредитов |
|---|---|---|---|
| **Ozon** | **название + продавец**: «Китайский чай Шу Пуэр…», продавец **Шуняня** (`/seller/shunana/`), статус `resolved` | 9.1–25.6 с | 35 |
| **Яндекс.Маркет** | **название + продавец**: «Листовой чай Да Хун Пао…», продавец «Чайный базар», статус `card_default` | 4.6–8.0 с | 10 |
| Wildberries | не идёт через API: работает напрямую за 7.70 ₽/мес | 0.6 с | 0 |

Три вещи, которые здесь неочевидны, и все три замерены:

**Рендеринг нужен Ozon и ломает Я.Маркет.** Без него Ozon отдаёт 13 КБ
интерстишла «Происходит перенаправление» (JS-рукопожатие не выполнено);
Яндекс с ним отдаёт 14.7 КБ с пятью маркерами капчи вместо карточки. Один
флаг, противоположные знаки.

**Сокращение ссылки — только для Ozon.** Домен `ozon.ru` закрыт на
бесплатном тарифе поставщика («We disabled the target domain for free
packages»), и короткая ссылка этот гейт обходит. Но `market.yandex.ru` не
закрыт, и через ту же сокращалку он отдаёт 2.57 МБ общей страницы с капчей
вместо карточки — промежуточный хоп `sba.yandex.ru/redirect` уводит с
карточки. **Это обход тарифного ограничения, он виден поставщику** (он сам
возвращает заголовок `scrape.do-target-url` с разрешённым адресом) и потому
временный: легальный путь — платный тариф, где домен открыт по прямому URL.
`tinyurl.com` в их блок-листе уже есть.

**Продавец Я.Маркета не подтверждён офферу.** На карточке он назван только в
`og:title`, а параметр выбора оффера `do-waremd5` в теле отсутствует вовсе —
значит отдан оффер по умолчанию. Поэтому имя уходит в отдельное поле
`seller.unverified_name`, а `seller.name` остаётся `null`: наивное чтение
одного поля не должно записать продавца чужого оффера.

**Ozon в потолок 15 с не укладывался надёжно, и это исправлено потолком в
30 с.** Наблюдения: 9 098, 9 834, 10 754, 11 998, 12 505, 12 688, 13 178,
>13 503 (×4), 25 633 мс. Ступень получала 13.5 с — исход был примерно
поровну `200` и `202`. Теперь она получает **27 150 мс**: это 25 633
самого медленного наблюдения плюс 1 500 на сокращение ссылки, которые
транспорт вычитает при промахе кэша коротких ссылок. Живая проверка после
правки: 14 334 мс, `200`, название и продавец.

Цена компромисса названа в коде: резидуал становится 2 065 мс, то есть
меньше гарда спейсинга Ozon (5 000). Значит `202` из-за занятого слота
возможен — но слот занят только если предыдущий запрос к Ozon был менее
пяти секунд назад, а при потоке 0–10 ссылок в сутки это пренебрежимо.

Кэш коротких ссылок (`outbound_shortlink`) вернул ступени 1.5 с её окна:
повторное сокращение одной и той же ссылки на каждый запрос стоило ровно
столько, а окно выросло с 12 000 до 13 503 мс.

### Дефект, который стоил ложного диагноза по маркетплейсу

Чтение Open Graph требовало порядка атрибутов `property` → `content`. Ozon
так и отдаёт. Яндекс отдаёт наоборот: `<meta content="…" property="og:url">`.
Регулярка не совпадала **никогда**, из этого `ym.identity()` возвращал
`None`, а классификатор делал вывод «ни og:url, ни canonical — это не наша
страница» и отдавал `SILENT_EMPTY`. Этот вердикт входит в `CHARGES_PROXY`,
то есть **исправно работающий адрес получал улику против себя за корректно
отданную карточку** и приближался к замене за деньги.

Чтение мета-разметки вынесено в `mktlink/extract/htmlmeta.py` и больше не
предполагает порядок атрибутов. Регрессия закреплена тестом, который
проверяет ровно старую форму выражения.

### Атрибуция егресса: чужой адрес не влияет на здоровье нашего

`_record` вписывал `egress='proxy'` литералом при любом транспорте. С
появлением скрейпинг-API это стало прямой порчей: капча с ЧУЖОГО адреса
писалась как улика против нашего IPv4. Обратная половина не лучше — успех
чужим адресом начислял бы заслугу нашему, и мёртвый адрес держали бы в пуле
вечно. Теперь `egress` — параметр, значение `'api'` добавлено в схему, а
строки здоровья для чужого егресса не создаётся вовсе; сырое наблюдение в
`proxy_attempt` при этом пишется всегда, со своим настоящим егрессом.

### Что здесь не замер, а гипотеза

Формы коротких ссылок, пути к продавцу и антибот-вердикты помечены в коде как
гипотезы. Пока путь не снят с живой карточки, лейн честно отдаёт
`seller_status = unknown_layout` — это правильное поведение, а не поломка.

```bash
mkt selectors     # покажет, кто ещё работает на догадках
```

Самая крупная непроверенная ставка: весь тёплый путь стоит на том, что
Camoufox-jar переигрывается через `curl_cffi`. На Ozon проверить её не
удалось — там блокируется сам адрес, до всякого отпечатка. Остаётся
проверить на Wildberries и Я.Маркете.

Попутно выяснилось, что **точного совпадения версий не бывает**: Camoufox —
это Firefox 152, а самая новая цель curl_cffi 0.16.3 — `firefox147`. У двух
инструментов независимые циклы релизов, поэтому сверка проверяет
совместимость с названным допуском (`MAX_MAJOR_GAP = 8`), а не равенство.
Первая редакция требовала равенства и заблокировала бы минтинг целиком.

## Устройство

```
mktlink/                 # ЕДИНСТВЕННЫЙ пакет репозитория
├── constants.py     физика (DNS, TCP, накладные) — от ручки не зависит
├── budget.py        всё, что от ручки зависит; тождество Σcap+Σguard+резидуал == NET
├── timing/          один абсолютный дедлайн, каждый таймаут — срез от остатка
├── urls/            реестр, валидация, SSRF, раскрутка, каноникализация
├── egress/          curl_cffi, отпечаток, jar, гард спейсинга
├── extract/         normalize (копия), сканер JSON, якорный поиск продавца
├── marketplaces/    вердикты, селекторы, три лейна, проход по лестнице
├── proxy6/          клиент, ошибки, кодек descr, чистый планировщик
├── store/           SQLite: 18 таблиц, денежные потолки триггерами
└── api/             схемы, ошибки, оркестратор, приложение
```

Два процесса: `api` обслуживает запросы, `forge` держит браузер и владеет
proxy6. Разделение — единственная проверяемая в CI формулировка запрета
браузера на пути запроса: в образе `api` нет ни `camoufox`, ни `playwright`,
поэтому браузер там не импортируется, потому что его там нет.

## Установка и настройка с нуля

Раздел рассчитан на человека, который этот проект раньше не видел. Ничего
знать заранее не нужно. Порядок шагов не случайный: **первые два шага не
требуют ни одной регистрации и ни одного рубля**, и после них сервис уже
отвечает по Wildberries. Регистрации нужны только для Ozon и Яндекс.Маркета,
и почему — объяснено на своём шаге.

### Что вообще происходит с вашей ссылкой

Прежде чем настраивать, полезно понимать, за что вы платите на каждом шаге.
Сервис получает ссылку и проходит по ней такой путь:

1. **Проверка.** Ссылка разбирается и сверяется с закрытым списком: три
   маркетплейса, конкретные формы путей. Ссылка на чужой магазин, на категорию
   или на внутренний адрес отсекается за миллисекунды и не тратит ничего.
2. **Раскрутка, если ссылка короткая.** `ozon.ru/t/AbC123` — это не адрес
   товара, а перенаправление. Сервис проходит по нему и получает настоящий
   URL. Результат кладётся в базу **навсегда**: короткая ссылка не меняет
   того, куда ведёт, поэтому второй раз это бесплатно.
3. **Кэш.** Если этот товар уже спрашивали недавно — ответ отдаётся из кэша за
   единицы миллисекунд, не обращаясь к маркетплейсу вовсе.
4. **Запрос к маркетплейсу.** Вот здесь тратятся деньги и время, и по-разному
   для разных магазинов:
   * **Wildberries** отвечает на обычный HTTP-запрос с любого адреса. Это
     самый дешёвый случай: 0.6 секунды, ноль затрат.
   * **Яндекс.Маркет** и **Ozon** с адреса вне России не отвечают: Яндекс
     показывает капчу, Ozon — страницу блокировки. Им нужен российский адрес,
     и мы берём его в аренду у скрейпинг-сервиса — по запросу, а не насовсем.
5. **Разбор.** Из полученной страницы достаётся название и продавец. Продавец
   ищется **только по якорям** — по ссылке на магазин, по идентификатору. Если
   якорь не найден, сервис отдаёт `null` и честный статус, а не первое похожее
   слово со страницы.
6. **Ответ.** Всегда одна и та же форма тела, для успеха и для отказа.

Главное следствие для настройки: **Wildberries работает сразу, а Ozon и
Яндекс.Маркет требуют одного ключа.**

### Шаг 1. Поставить (5 минут, ничего покупать не нужно)

Нужен Python 3.12 и [uv](https://docs.astral.sh/uv/) — менеджер окружений.
Если `uv` нет:

```bash
curl -LsSf https://astral.sh/uv/install.sh | sh
```

Дальше:

```bash
git clone <адрес-репозитория> && cd market_parser
uv venv                              # создаст .venv
uv pip install -e ".[dev]"            # зависимости пути запроса
cp .env.example .env                  # настройки; править пока НЕ нужно
uv run mkt init-db                    # создаст файл базы data/mktlink.sqlite
```

Проверка, что установка жива:

```bash
uv run pytest -q                      # 650 тестов, сети не требуют
uv run ruff check .
```

Запуск:

```bash
uv run uvicorn mktlink.api.app:factory --factory
```

Сервис поднимется на `http://127.0.0.1:8000`.

> Обратите внимание на `:factory`, а не `:create_app`. Прежняя команда в
> этом README указывала на `create_app` и **не работала никогда**:
> `uvicorn --factory` вызывает фабрику без аргументов, а `create_app`
> требует зависимости. Нашлось это буквальным прохождением этой самой
> инструкции. Та же ошибка была и в `Dockerfile`.

### Шаг 2. Первый запрос — Wildberries уже работает

Откройте второй терминал:

```bash
curl -s -X POST http://127.0.0.1:8000/v1/product \
  -H 'Content-Type: application/json' \
  -d '{"url":"https://www.wildberries.ru/catalog/430803464/detail.aspx"}' | python3 -m json.tool
```

Ожидаемый ответ. Замерено на чистой установке **без единого ключа**, время
0.4–0.5 с (три прогона: 397, 442, 461 мс):

```json
{"status": "ok",
 "url": {"canonical": "https://www.wildberries.ru/catalog/430803464/detail.aspx", "hops": 0},
 "marketplace": "wb",
 "product": {"name": "Да Хун Пао настоящий чай улун Большой Красный халат", "sku_id": "430803464"},
 "seller": {"name": "BASKEY", "id": "55588", "kind": "third_party", "status": "resolved"},
 "meta": {"cache": "miss", "elapsed_ms": 397}}
```

Повторите ту же команду — придёт `"cache": "hit"` за единицы миллисекунд.

Если вместо этого пришло `"status": "pending"` — смотрите таблицу
[«Если не работает»](#если-не-работает) ниже.

### Шаг 3. Ozon и Яндекс.Маркет — нужен российский адрес

**Почему.** Замерено с датацентрового адреса вне России:

| маркетплейс | ответ с нашего адреса |
|---|---|
| Wildberries | `200`, название и продавец получены |
| Яндекс.Маркет | `302` → `/showcaptcha`, страница «Вы не робот» |
| Ozon | `403`, страница «Похоже, нет соединения», 2 cookie вместо 15–25 |

Причина не в VPN и не в качестве нашего кода: адрес одновременно **не
российский и не резидентный** (хостинг). Свой VPN на хостинге проблему не
решает — проверено. Нужен либо российский резидентный адрес в аренду, либо
сервис, который держит такие адреса за вас. Второе дешевле и быстрее.

#### 3.1. Зарегистрироваться в scrape.do

1. Откройте **[scrape.do](https://scrape.do/)** и нажмите регистрацию.
   Достаточно почты, карта на бесплатном тарифе не нужна.
2. После входа откроется дашборд. Там будет **API token** — строка примерно
   из 40 символов вида `1dfb5e1ac9dc4dfebc1b4efd185c506443926d8096b`.
   Скопируйте её.
3. Бесплатный тариф даёт **1000 кредитов в месяц**. Проверить остаток можно
   в любой момент:

```bash
curl -s "https://api.scrape.do/info?token=ВАШ_ТОКЕН"
# {"IsActive":true,"MaxMonthlyRequest":1000,"RemainingMonthlyRequest":1000, ...}
```

**Сколько кредитов на что уходит** (замерено):

| запрос | кредитов | сколько таких в месяц бесплатно |
|---|---:|---:|
| Яндекс.Маркет | 10 | ~100 |
| Ozon | 35 | ~28 |

#### 3.2. Прописать токен

Откройте `.env` и раскомментируйте/впишите:

```bash
MKTLINK_SCRAPEDO_TOKEN=ваш_токен_отсюда
```

Перезапустите сервис. Яндекс.Маркет заработает сразу:

```bash
curl -s -X POST http://127.0.0.1:8000/v1/product \
  -H 'Content-Type: application/json' \
  -d '{"url":"https://market.yandex.ru/card/da-khun-pao/101814267477"}' | python3 -m json.tool
```

Придёт `"status": "ok"` за 4–8 секунд, с названием товара. **Продавец придёт в
поле `seller.unverified_name`, а не в `seller.name`** — и это не ошибка, а
намеренная честность: на карточке Яндекса продавец назван только в
мета-разметке, а параметра выбора оффера в ней нет вовсе. Значит это продавец
оффера **по умолчанию**, и подтвердить, что он тот же, что в вашей ссылке,
по этой странице нельзя. Проверяйте `seller.status` — там будет
`card_default`.

#### 3.3. Ozon: один дополнительный шаг

Ozon на бесплатном тарифе scrape.do **закрыт**: их проверка на входе не
пропускает домен `ozon.ru`, ответ будет

```json
{"StatusCode":400,"Message":["We disabled the target domain for free packages.
 Please upgrade your account or contact with us for trial."]}
```

Три варианта, по возрастанию честности:

1. **Платный тариф.** Hobby — $29/мес, 250 000 кредитов, то есть около 10 000
   карточек Ozon. На платном тарифе домен открыт по прямому URL, и никаких
   дополнительных настроек не нужно. У каждого платного тарифа есть
   бесплатный триал — им можно проверить, что всё работает, до оплаты.
2. **Написать в их поддержку** (`support@scrape.do`) и попросить открыть
   `ozon.ru` на триале или бесплатном тарифе. Их же сообщение об ошибке это
   предлагает. Если у вас единицы запросов в сутки, 40 карточек в месяц
   бесплатного тарифа может хватить.
3. **Обход через сокращалку.** Технически работает: если подать вместо адреса
   Ozon короткую ссылку, проверка видит домен сокращалки и пропускает запрос.
   Включается так:

```bash
MKTLINK_SCRAPEDO_SHORTEN_VIA=clck     # none | clck | goo
```

   **Это обход тарифного ограничения, и он временный.** Поставщик видит
   разрешённый адрес — он сам возвращает его в заголовке
   `scrape.do-target-url`. Список сокращалок они пополняют: `tinyurl.com` там
   уже есть. Держать это в продакшене — значит однажды получить отключённый
   аккаунт посреди работы. Дефолт `none` намеренно: обход включается явным
   решением, а не по забывчивости. Подробности и риски — в докстроке
   `mktlink/egress/shortener.py`.

После этого:

```bash
curl -s -X POST http://127.0.0.1:8000/v1/product \
  -H 'Content-Type: application/json' \
  -d '{"url":"https://ozon.ru/t/8M3J7yH"}' | python3 -m json.tool
```

Ozon отвечает **9–26 секунд** — это его нормальное время через скрейпинг-API
с рендерингом на стороне поставщика, а не признак проблемы. Именно поэтому
потолок ответа поднят до 30 секунд. Продавец здесь придёт в `seller.name` со
статусом `resolved`: на карточке Ozon он привязан ссылкой на магазин, то есть
подтверждён.

### Шаг 4. Свой прокси для Wildberries — необязательно

Wildberries работает без прокси, поэтому этот шаг можно пропустить совсем.
Он нужен, если вы хотите **не ходить к маркетплейсу с адреса своего сервера**:
адрес один, его репутацию вы не контролируете, и если WB однажды начнёт его
ограничивать, менять будет нечего.

1. Зарегистрируйтесь на **[proxy6.net](https://proxy6.net/)**.
2. Пополните баланс. IPv4 Shared стоит порядка **7–8 ₽ в месяц** за адрес.
3. Возьмите API-ключ: **[proxy6.net/ru/user/api](https://proxy6.net/ru/user/api)**
   (описание методов — [proxy6.net/ru/developers](https://proxy6.net/ru/developers)).
4. Впишите в `.env`:

```bash
MKTLINK_PROXY6_API_KEY=ваш_ключ
MKTLINK_PROXY6_COUNTRY=ru
MKTLINK_PROXY6_PERIOD_DAYS=7      # короткий срок намеренно: неудачная
                                  # покупка должна дёшево истечь
```

Сервис купит **ровно один** адрес при первой необходимости и будет растить пул
только заменой. Впрок не закупается никогда. Посмотреть пул и траты:

```bash
uv run mkt proxy ls
uv run mkt proxy spend
```

**Чего этот ключ НЕ решает.** Ozon и Яндекс.Маркет он не открывает: proxy6
продаёт датацентровые адреса, а им нужны резидентные. Это замерено, и переход
на более дорогой тариф v4 внутри proxy6 задачу тоже не решает — выделенность
адреса не меняет его принадлежность датацентру.

### Шаг 5. Redis — необязательно

Кэш и без него работает: память процесса плюс SQLite. Redis добавляет то, чего
эти два уровня не дают — **общий кэш между процессами и переживание
перезапуска**. Смысл в кредитах: карточка Ozon стоит 35 из 1000 в месяц, и
промах кэша — это не потерянная секунда, а треть процента месячной квоты.

```bash
docker run -d --name mktlink-redis -p 6379:6379 redis:7-alpine
uv pip install -e ".[redis]"
```

и в `.env`:

```bash
MKTLINK_REDIS_URL=redis://localhost:6379/0
```

Если Redis недоступен или упал — запрос **не падает**: недоступный ускоритель
означает промах кэша, то есть обычный путь к маркетплейсу. Источником истины
остаётся SQLite.

### Шаг 6. Браузер (forge) — сейчас не нужен

В репозитории есть отдельный процесс `forge` с анти-детект браузером Camoufox.
Он ставится своим окружением:

```bash
uv pip install -e ".[forge]" && uv run python -m camoufox fetch
```

**В текущей рабочей конфигурации он не нужен.** Он был написан, чтобы снимать
cookie для Ozon с собственного адреса, а с нашего адреса Ozon страницу не
отдаёт вовсе — проверено настоящим Camoufox 152. Сейчас Ozon идёт через
скрейпинг-API, где браузер работает на стороне поставщика. Ставьте `forge`,
только если появится российский резидентный адрес и захочется проверить путь
без платного API.

## Все настройки

Все переменные читаются из `.env` в текущем каталоге, префикс `MKTLINK_`.
Ни один модуль пакета не обращается к переменным окружения напрямую — только
`mktlink/settings.py`.

| переменная | дефолт | зачем |
|---|---|---|
| `MKTLINK_RESPONSE_BUDGET_MS` | `30000` | Потолок времени ответа, 5000…30000. Тридцать секунд нужны только Ozon |
| `MKTLINK_DB_PATH` | `data/mktlink.sqlite` | Файл базы |
| `MKTLINK_SCRAPEDO_TOKEN` | — | Ключ скрейпинг-API. **Без него Ozon и Я.Маркет недостижимы** |
| `MKTLINK_SCRAPEDO_MARKETPLACES` | `["ozon","ym"]` | Кто идёт через API. WB здесь нет намеренно: он работает бесплатно |
| `MKTLINK_SCRAPEDO_SHORTEN_VIA` | `none` | `none` — легальный путь (нужен платный тариф). `clck`/`goo` — обход гейта |
| `MKTLINK_PRODUCT_TTL_S` | `86400` | Срок свежести ответа, секунды. Потолок — неделя |
| `MKTLINK_PRODUCT_TTL_PINNED_S` | `604800` | То же для ссылки с закреплённым оффером. `0` = как у обычной |
| `MKTLINK_REDIS_URL` | — | Опциональный общий кэш |
| `MKTLINK_PROXY6_API_KEY` | — | Свой прокси для WB. Ozon и Я.Маркет не открывает |
| `MKTLINK_PROXY6_PERIOD_DAYS` | `7` | Срок закупки |
| `MKTLINK_YM_REGION_ID` | `213` | Регион Я.Маркета (213 — Москва) |
| `MKTLINK_LOG_LEVEL` | `INFO` | |

## Два эндпоинта и когда какой

### `POST /v1/resolve` — только развернуть ссылку

Берёт короткую ссылку, возвращает полную. **К карточке не обращается вовсе**,
поэтому не тратит ни кредитов, ни времени на рендеринг.

```bash
curl -s -X POST http://127.0.0.1:8000/v1/resolve \
  -H 'Content-Type: application/json' \
  -d '{"url":"https://ozon.ru/t/8M3J7yH"}'
```

Результат кэшируется в базе **без срока** — короткая ссылка неизменяема.
Второй запрос той же ссылки: **2 миллисекунды**. Ключ нормализован, поэтому
`ozon.ru/t/X`, `www.ozon.ru/t/X` и `ozon.ru/t/X?utm_source=tg` — одна запись
(последнее написание приходит чаще всего, когда ссылку пересылают из
мессенджера).

Название и продавец в ответе будут `null`, и `seller.status` будет
`not_requested` — «не искали», а не «не нашли».

**Когда использовать:** клиент хочет привести ссылку к нормальному виду и
сохранить её у себя. Развернув один раз, за раскрутку он больше не платит
никогда.

### `POST /v1/product` — развернуть и разобрать

Принимает и короткую ссылку, и полную. Короткую разворачивает через тот же
кэш, что и `/v1/resolve`, поэтому если ссылка уже разворачивалась — это
бесплатно.

```bash
curl -s -X POST http://127.0.0.1:8000/v1/product \
  -H 'Content-Type: application/json' \
  -d '{"url":"https://ozon.ru/t/8M3J7yH","max_stale_s":86400}'
```

Параметры тела:

| поле | дефолт | смысл |
|---|---|---|
| `url` | обязательно | Ссылка, короткая или полная |
| `max_wait_ms` | потолок сервиса | Может только **понизить** бюджет |
| `max_stale_s` | `86400` | Согласие принять устаревший ответ и его максимальный возраст. `0` — не отдавать устаревшее вовсе |
| `force_refresh` | `false` | Сходить к маркетплейсу, игнорируя кэш. Вчетверо дороже по квоте |

У обоих эндпоинтов есть и `GET`-форма с теми же параметрами в query — удобно
проверять из браузера.

## Проверка, что всё работает

```bash
curl -s http://127.0.0.1:8000/healthz
# {"ok":true}

curl -s http://127.0.0.1:8000/readyz
# {"ok":true,"budget_ms":30000,"client_timeout_hint_ms":30500}
```

`client_timeout_hint_ms` — то, что сервис просит поставить таймаутом на
вашей стороне: он обязан быть больше нашего потолка, иначе вы оборвёте
запрос, который успел бы.

Полезные команды:

```bash
uv run mkt budget --budget-ms 30000   # что бюджет делает с лестницами
uv run mkt proxy ls                   # пул адресов и их состояние
uv run mkt proxy spend                # сколько потрачено за 30 дней
uv run mkt selectors                  # какие пути ещё на гипотезах
```

## Если не работает

| симптом | причина | что делать |
|---|---|---|
| `"status":"pending"`, `reason: no_warm_jar` на Ozon или Я.Маркете | Не задан `MKTLINK_SCRAPEDO_TOKEN` — этим двум нужен российский адрес | Шаг 3 |
| `"status":"pending"` на **Wildberries** | Такого быть не должно: WB работает без ключей | Проверьте, что база создана: `uv run mkt init-db` |
| `500`, `capacity_exhausted`, в логах `DomainDisabled` | `ozon.ru` закрыт на бесплатном тарифе scrape.do | Шаг 3.3 |
| `"reason":"marketplace_challenge"` на Я.Маркете | Запрос ушёл **не** через API: маркетплейс не в `SCRAPEDO_MARKETPLACES` или токен пуст | Проверьте `.env` |
| `"status":"pending"`, `reason: deadline_exhausted` на Ozon | Поставщик отвечал дольше потолка. Нормально в редких случаях: замеры 9–26 с | Повторить. Если постоянно — проверьте, что `RESPONSE_BUDGET_MS=30000` |
| `"seller":{"name":null,"status":"card_default"}` на Я.Маркете | Не ошибка. Продавец найден, но не подтверждён вашим оффером | Читайте `seller.unverified_name`, см. шаг 3.2 |
| `"seller":{"name":null,"status":"unknown_layout"}` | Разметка маркетплейса изменилась, якорь не найден | `uv run mkt selectors`, затем перепиннить путь по живой карточке |
| `422 invalid_url` / `host_not_allowed` | Ссылка не на один из трёх маркетплейсов, либо это категория, а не товар | Проверьте ссылку |
| `422`, `detail.unwind` в ответе | Короткая ссылка сломана: цикл, слишком много переходов, увод на другой маркетплейс | Ссылка нерабочая |
| `429 rate_limited` | Исчерпана квота вашего API-ключа | Ждать `Retry-After` |
| Остаток кредитов scrape.do падает быстрее ожидаемого | Кэш не работает, либо кто-то шлёт `force_refresh` | Проверьте `meta.cache` в ответах; включите Redis (шаг 5) |

## Сколько это стоит в месяц

| что | цена | нужно ли |
|---|---|---|
| Wildberries | **0 ₽** | работает сразу |
| Яндекс.Маркет, до ~100 запросов | **0 ₽** (бесплатный тариф scrape.do) | нужен только токен |
| Ozon, до ~28 запросов | **0 ₽**, если поддержка откроет домен | иначе см. ниже |
| Ozon, до 10 000 запросов | **$29/мес** (scrape.do Hobby) | если Ozon нужен всерьёз |
| Свой прокси для WB | **7–8 ₽/мес** | необязательно |
| Redis | 0 ₽ (свой контейнер) | необязательно |

При потоке в единицы ссылок в сутки бесплатных тарифов хватает целиком.
Платить приходится только за Ozon и только если запросов к нему больше
трёх десятков в месяц.

## Что надо сделать до первой строки продакшена

Phase 0 — блокирующий гейт, а не разминка. Три замера, около 40 ₽:

1. Снять живой payload карточки Ozon и Я.Маркета, запинить пути к продавцу.
2. Три карточки с датацентрового IPv4, по 20 попыток за три дня: доля капчи,
   молчаливой пустоты и успеха. Это превращает таблицу выше из ожидания в
   замер.
3. Расшарить карточку из мобильных приложений и записать реальные хосты
   коротких ссылок.

Пункты 1 и 3 блокирующие: без них лейн отдаёт `unknown_layout` на каждом
запросе, а короткие ссылки распознаются по угаданным формам.
